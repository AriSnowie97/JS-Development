
# Lab 1-3

## Опис
Папка `Lab 1-3` містить лабораторні роботи 1-3 для курсу з розробки JavaScript.

## Вміст
- **Lab 1**: Введення в JavaScript
- **Lab 2**: Змінні та типи даних
- **Lab 3**: Функції та область видимості

## Мета
Набути практичних навичок у написанні JavaScript коду через виконання серії вправ.

## Вимоги
- Базові знання HTML та CSS
- Текстовий редактор (VS Code, Sublime Text тощо)
- Node.js встановлений (опціонально для запуску скриптів)
- Сучасний браузер з DevTools
