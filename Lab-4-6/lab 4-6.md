# Lab 4-6

## Опис папки

Папка **Lab 4-6** містить матеріали для лабораторних робіт 4-6 з курсу JavaScript розробки.

## Структура

- **Файли завдань** - постановки задач для виконання
- **Початкові шаблони** - стартові файли для кодування
- **Приклади розв'язків** - референтні реалізації

## Теми, що охоплюються

- Робота з DOM (Document Object Model)
- Обробка подій (Event Handling)
- Асинхронне програмування (Promises, Async/Await)
- Робота з API запитами (Fetch)
- Маніпуляція стилями та класами

## Як використовувати

1. Прочитайте постановку задачі
2. Реалізуйте рішення у відповідному файлі
3. Протестуйте функціональність
4. Зверніться до прикладів, якщо потрібна допомога
